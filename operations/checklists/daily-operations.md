# Daily Operations Checklists

---

## OPENING CHECKLIST (7:00 AM)

### Manager
- [ ] Arrive 7:00, disable alarm
- [ ] Turn on lights, AC, music
- [ ] Check refrigerator temperatures (log in temp sheet)
- [ ] Review inventory — enough for the day?
- [ ] Check PedidosYa tablet is online
- [ ] Review any special orders / reservations
- [ ] Brief team on daily specials / Stroopwafel del Mes

### Barista
- [ ] Turn on espresso machine (needs 15-20 min warmup)
- [ ] Purge group heads
- [ ] Pull test shots, dial in grind (18g in, 36g out, 25-30 sec)
- [ ] Prepare milk pitchers, jugs
- [ ] Fill cold brew station / check cold brew supply
- [ ] Stock cups, lids, napkins, sugar packets
- [ ] Prepare syrups (stroopwafel, speculoos, vanilla, chocolate)

### Baker / Stroopwafel Station
- [ ] Turn on stroopwafel irons (10 min preheat)
- [ ] Prepare dough (if not prepped night before)
- [ ] Portion dough balls
- [ ] Make first batch of caramel syrup / check existing
- [ ] Prep toppings: slice fruit, portion Nutella, whipped cream
- [ ] Stock poffertjes batter
- [ ] Heat deep fryer (if bitterballen on menu today)
- [ ] Set up display case with appeltaart, tompouce

### Front of House
- [ ] Clean all tables and chairs
- [ ] Wipe windows and mirrors
- [ ] Fresh flowers/tulips on tables
- [ ] Menu stands on all tables
- [ ] POS system powered on and tested
- [ ] Cash register counted, starting cash verified
- [ ] WiFi working

### DOORS OPEN: 8:00 AM

---

## MIDDAY CHECKLIST (12:00-13:00)

- [ ] Restock stroopwafel dough balls
- [ ] Restock toppings
- [ ] Check milk supply
- [ ] Clear and clean tables
- [ ] Empty trash if >75% full
- [ ] Restock takeaway supplies
- [ ] Check PedidosYa orders are being fulfilled <15 min

---

## CLOSING CHECKLIST (20:00)

### Barista
- [ ] Turn off espresso machine
- [ ] Clean portafilters, group heads, steam wands
- [ ] Backflush with detergent (daily)
- [ ] Empty knock box, clean
- [ ] Wipe down machine exterior
- [ ] Restock beans for tomorrow

### Baker / Kitchen
- [ ] Turn off stroopwafel irons
- [ ] Turn off deep fryer, filter oil
- [ ] Clean all prep surfaces
- [ ] Prep dough for tomorrow (refrigerate)
- [ ] Cover and refrigerate all toppings
- [ ] Inventory check — note low items for morning order
- [ ] Take out trash

### Front of House
- [ ] Clean all tables and chairs
- [ ] Sweep and mop floors
- [ ] Clean display case
- [ ] Wipe all glass surfaces
- [ ] Organize retail display
- [ ] Cash register: count, reconcile, prepare deposit
- [ ] Lock POS tablet

### Manager
- [ ] Review daily sales numbers
- [ ] Note any issues / customer feedback
- [ ] Place ingredient orders if needed
- [ ] Check social media — respond to any comments/DMs
- [ ] Post daily Instagram story (if not done)
- [ ] Set alarm, lock up, lights off (except security)
